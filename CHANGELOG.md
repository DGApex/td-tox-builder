# Changelog

All notable changes to this project are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),

## [1.0.0] - 2026-10-01

### Added

- `SKILL.md` with the full build workflow: spec elicitation, build script generation,
  optional bootstrap script, cache-proof run instructions and troubleshooting.
- `reference.md` with the TouchDesigner Python API cheatsheet and gotcha catalog G1-G34.
- `component-design.md` with the operator-facing design doctrine.
- `debugging.md` with the diagnosis method for silent TouchDesigner failures.
- Build script template, ASCII-only PowerShell bootstrap template and portable
  preflight helpers.
- Offline checks for namespace handoffs (G26), blend menu IDs (G27) and preflight
  helpers (G29, G30).
